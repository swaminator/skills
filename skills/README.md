# Skills Catalog

This staging branch is synced from upstream and features only verified skills with completed evaluations. To verify a featured skill, look for the `*.oms.sig` signature file in the skill folder and open its `evals.json` file to review the completed evaluation coverage.

At the upstream commit used for this branch, no skill currently has both files, so this directory intentionally contains no product skill folders.

When upstream adds skills that satisfy both gates, those skill folders should be retained here and all other skill folders should remain pruned from this branch.
