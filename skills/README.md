# Skills Catalog

This staging branch is synced from upstream and filtered to include only skills that contain both an `evals.json` file and a `*.oms.sig` signature file.

At the upstream commit used for this branch, no skill matched both requirements, so this directory intentionally contains no product skill folders.

When upstream adds skills that satisfy both gates, those skill folders should be retained here and all other skill folders should remain pruned from this branch.
